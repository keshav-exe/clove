Clove 3.2 updates itself.

- **Automatic updates:** Clove checks once a day, downloads new versions in the background, and installs them when you quit. Every update is signed, and Clove won't install one that isn't. Turn it off, or check now, in Settings, About.
- **A proper update window:** release notes show up formatted and scrollable, with Install and Later, in the same window most Mac apps use.
- **Coming from 3.1 or earlier:** this one last update opens the download in your browser. Drag Clove to Applications once, and from then on it updates itself.
