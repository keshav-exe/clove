Clove 2.0 brings your skills, your agents' setup, and what they leave behind into one native Mac app.

- **Home:** what needs a look and what's trending on skills.sh, at a glance.
- **Discover:** browse skills.sh and install a skill everywhere or into one project.
- **Context and Tools:** CLAUDE.md and AGENTS.md files, rules, slash commands, subagents, MCP servers, hooks, and permissions for every agent.
- **Sharing:** link one instruction file, command, subagent, or MCP server across Claude Code, Cursor, and Codex.
- **Secrets:** move API keys out of your dotfiles and into the Keychain, with access on demand.
- **Running:** live agent sessions, MCP servers, and dev servers, with stop.
- **Cleanup:** unused skills and commands, old session history, and leftovers like Chrome for Testing builds.

Thanks to [Ram (@ramxcodes)](https://x.com/ramxcodes/status/2113292890294423802) for the ideas behind project installs, hooks and AGENTS.md support, sharing setup across agents, and Secrets.
