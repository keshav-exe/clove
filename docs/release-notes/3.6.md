Clove 3.6 opens the notch for a moment when an agent starts or finishes a task, rebuilds Settings from the ground up, and stops asking for your password to show Claude's limits.

- **Agents, at a glance:** when an agent starts a task you sent it, the notch opens into a small card: the app it's in, the conversation, what it's doing, and a glow breathing along the bottom in that app's colours. It folds back after a few seconds. When the task ends, the same card shows the agent's last words and a Show button. Turn it off in Settings › General.
- **Settings, rebuilt:** every pane now looks like System Settings, with switches, icons, and a line under each option saying what it does. Drag Now's sections and the notch's tabs into the order you want, with a live drawing of the notch that follows along. Pick between the notch and the menu bar from two pictures, and see every shortcut as keycaps.
- **No more password prompts:** Clove reads Claude Code's sign-in the same way Claude Code saves it, so macOS no longer asks for your password each time Claude Code refreshes it. Settings › Now explains exactly what's read and where it goes.
- **The right app, every time:** a conversation in T3 Code shows T3 Code even after Clove restarts, and two apps working in the same project no longer get mixed up.
