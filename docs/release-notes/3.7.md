Clove 3.7 brings a Dynamic Island to displays without a notch, and slims down what sits beside the notch while agents work.

- **Dynamic Island:** on an external display, or a Mac without a notch, Clove is now a black pill floating in the menu bar instead of a stand-in notch. Like a Live Activity, it's out of sight until something's live: while an agent works, it shows the app's icon and what the agent is working on. Hover the top of the screen to open it, and announcements and the panel grow out of it as one floating card.
- **On the display you're using:** Settings › General › Show on puts the island on the built-in display or on whichever display holds the window you're working in. It moves only while it's closed, so an open panel never jumps away.
- **Slimmer ears:** the app icon and status dot beside the notch take less room, so the notch no longer looks oversized while an agent works. Turn them off with "Agents at work beside the notch".
- **The right app:** a conversation is matched to the app that resumed it only when that app's agent was started for it, so a stray command line can't claim it.
